# 原生小程序真实后端联调 · 2026-11-12

本阶段经用户要求继续推进，目标是补齐已经识别的服务端缺口，并在一次性可写测试环境联调，不部署到旧生产站或杭州恢复演练，不修改 DNS，不上传/发布小程序。

## 范围

- 本人微信/QQ修改接口与通知标读的服务端归属校验。
- 发布者跨设备任务历史、参与方任务详情/联系方式/事件。
- 跑腿合法状态推进、抢单/选择报名人的互斥、重复报名与过期任务保护。
- 真正的完成码：仅发布者可生成、仅实际接单者可核销；只存哈希，有限有效期和失败尝试上限，不在公开摘要返回码或哈希。
- 原生小程序接入真实接口，移除对应“暂不支持”文案；保持4Tab和当前美学。
- 加入全新 V17（若需要保存码有效期/尝试次数）；V1–V16保持不变。

## 验证环境

本机不安装 Java/Maven。使用旧服务器已有 Maven 镜像，仅挂载一次性源码目录与测试依赖缓存；测试数据库为容器内 H2，不挂生产目录/配置/数据，不连接生产 Docker 网络。依赖预取允许 Maven Central 网络访问，实际测试与测试应用优先禁止外联。限制CPU/内存，串行执行，不运行高负载并发压测。

首轮离线容器因无 Maven 缓存失败，属于环境准备失败而不是业务测试红灯。联系方式/通知实现后，联网下载依赖的一次性测试运行已通过9项；后续保留独立缓存，避免反复下载。

- 生产与恢复演练数据都保持原样，不重置真人密码。

- 不打印真实环境文件、密钥、密码散列、令牌；测试日志过滤认证材料。
