# 小程序启动备案展示 · 2026-11-16

## 展示方案

按用户提供的备案通过通知，当前显示 **浙ICP备2026099873号**。沿用原有品牌图、暖纸白、深蓝文字和少量金色分隔线；参考示例的留白和居中构图，不复制其他项目名称、作者、证书、更新按钮或版本号。

不添加第 11 个页面、不改变 4 Tab：公共 `launch-intro` 组件挂载在所有可能的入口页。每次小程序冷启动只由第一个组件领取展示机会，约 2.2 秒自动收起，也可点击“进入”跳过。不依赖登录或 API 成功，也不永久记录“已看过”；同一进程内切换页面、Tab 和从后台返回不会再次展示。从分享详情进入不会丢失原页面参数。

备案号只出现在启动展示或用户主动打开的详情里，业务页面无常驻备案页脚。点启动页的备案号会停止自动关闭，进入同一组件的详情视图；通行证末尾的“关于与备案”支持访客访问。退出视图、切页和卸载都会清理计时器，并通过已有 overlay 所有者集合恢复底栏，不干扰其他抽屉。

## 编号与查询边界

- 单一配置位置：`miniprogram/src/lib/filing.js`。
- 编号来源是用户提供的通知，并未独立读取微信后台完整的小程序备案记录。未自行补上任何 `-数字X` 或 `-数字A` 后缀；正式提审前应与对应小程序记录核对，而不是借用示例 APP 的后缀。
- 展示 `https://beian.miit.gov.cn/` 并提供主动复制网址按钮。未接入 web-view/业务域名，未把复制网址伪装为已经实现直接网页跳转。
- 工信部通知要求显著展示备案编号及提供备案系统查询链接。此处完成的是展示与可查阅入口，不能仅凭界面测试声称合规验收通过；提审前需核实完整编号与当时微信平台的查询跳转要求。
- 小程序备案完成不等于网站备案、正式 HTTPS、合法 request 域名或代码发布完成。

参考：[工信部关于开展移动互联网应用程序备案工作的通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)。
