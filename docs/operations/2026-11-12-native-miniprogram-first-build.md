## 已完成的代码

新增独立目录 `miniprogram/`，微信原生 WXML/WXSS/JavaScript，10 个页面、4 个 Tab，无 npm 运行时依赖。AppID `wx94d18423aab8b5df`，默认 API 指向未来正式域名 `https://ustc.suntomb.cn/api`。

- **跑腿**：校区与模式筛选、紧凑车票列表、抢单/报名抽屉、三步发布、参与方履约下一步、发布者选报名人/确认完成、履约问题反馈。
- **小店**：校区/类别/搜索、设计封面与真实服务预览、服务详情、日期时间预约、服务后联络信息受控复制；顾客和店主的轻量预约动作放在通行证。
- **宣传**：精选横卡、类型/校区筛选、纯文本详情、收藏/留言、联系方式规则；本机草稿、明确的服务器提交审核与重复创建保护。
- **通行证**：深墨蓝身份卡、真实信用与联络状态、三种业务身份协议、邮箱登录注册、任务/预约/宣传分段、通知、用户名/昵称与密码编辑。
- **共用能力**：原生底栏，正文可滚动的底部抽屉，安全区留白，轻微过渡与触觉反馈，中文状态映射，网络失败/空状态/重试。

没有管理页面、金融按钮、二手列表、地图、相册上传、微信一键登录或 web-view 套壳。用户源品牌图保持不变；Tab 图标单独制作，约束在原生要求的81px/40KB以内。

## 不照搬指南中过时或超过后端能力的部分

接口核对发现，指南的部分功能描述比当前实现更完整，首版没有用假交互掩盖这些差异：

1. **后端完成码参数未真正校验**：本端不显示“完成码核销”；使用合理的履约下一步和发布者确认。后端状态机/权限仍须在开放小程序写流量前加固。
2. **跑腿缺少联系方式、接单者详情和事件时间线接口**：不跨用户查询资料、不伪造字段；只显示当前状态进度。
3. **发布者完整跑腿历史接口缺失**：明确区分真实接单/报名历史与“我在本机发布”的设备记录，不宣称跨设备完整。
4. **联系方式更新接口缺失**：注册时填写微信/QQ；个人页可看但不提供假保存入口。已有用户名/昵称/密码接口正常接入。
5. **文件接口只有元数据和绑定**：不提供原生上传按钮；宣传附件仅列名称并说明暂不支持预览下载。
6. **宣传创建默认待审核**：本机草稿不调用服务器，明确提交才发送。保存成功而提交失败时保留服务器ID，不重复创建；结果不明时要求先核对。
7. **403 不等于登录失效**：只对明确401清理会话。网络错误保留令牌但阻止未验证的私人操作。旧响应、退出、换账号和重复提交均有回归覆盖。
8. **指南示例列出11页**：将通知、我的单据与账号编辑合入通行证，实际保持10页。

用户管理后台只在网页端。店主处理本人预约属于首版用户侧能力，不等同于站务管理。

## 怎样查看

### 正式工程

微信开发者工具导入仓库中的 `miniprogram/`。无需运行 `npm install`。正式 API 仍等待网站备案/域名/HTTPS到位，因此此时真实联网失败应作为环境限制展示，不返回虚构内容。

### 独立离线样例

已生成：

`.claude/verification/native-miniprogram/offline-preview/`

在微信开发者工具**另行导入这个目录**。原先计划使用 `touristappid`，后续实际工具拒绝该值，现改为沿用用户授权的 AppID 仅作本地打开，仍然全部使用隔离样例。所有页面标题有“样例”，合成任务/店铺/用户只在内存中，不转发业务网络请求、不发验证码、不创建真实订单。演示登录可填写任意非空用户名/密码，不能当成真实账号认证。

它用于确认四Tab、卡片和抽屉的实际视觉。**本轮没有取得模拟器截图，所以没有把代码推测或浏览器仿制图当成真实小程序截图。** 该目录不可上传、提审或发布。

用户需要在开发者工具「设置 → 安全设置 → 服务端口」开启 CLI 能力后，才能继续自动化模拟器交互。也可先手动导入查看，不需要修改服务器安全配置。
