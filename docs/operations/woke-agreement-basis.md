# 协议起草依据与上线前核对

本次把资金功能默认关闭，采用协议确认的身份申请方式。正式标题不等同于法律合规认证；没有宣称“免责条款可免除一切责任”。

## 起草依据

- [个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)：第6条最小必要，第13–14条合法处理依据和充分知情、自愿明确的同意，第17条告知，第23条对外提供及单独同意，第25条公开披露。
- [民法典全文（政府网站）](https://gdca.miit.gov.cn/zwgk/zcwj/flfg/art/2020/art_573d6ef5018b46b6a4e1f31ca085a710.html)：第496–497条格式条款的提示说明与效力边界，第506条不得免除的人身损害及故意、重大过失责任。
- [闲鱼社区隐私政策](https://terms.alicdn.com/legal-agreement/terms/suit_bu1_taobao/suit_bu1_taobao202103021554_43790.html)：仅参考按场景列明信息用途、争议核验和共享边界的结构；不照搬商业平台的主体、资质和免责安排。

## 已落实到版本正文

- 新申请跑腿员/闲置发布者主动确认后免费开通；店主理人仍由站务核验。
- 不得侵占或食用受托餐品，不得收款后失联或拒不交付；服务信息须真实。
- 争议核查限于平台内实际提供的邮箱和联系方式、与争议相关的业务记录；不把占位学号/姓名/电话描述成实名信息。
- 平台查阅与向外部提供、公开披露是不同的行为；一次勾选不是无限对外披露授权。
- 不增加 IP、设备指纹采集；保留版本正文、身份、服务器同意时间。
- 既有身份不补签、不伪造历史同意；原资金记录不清零、不自动退款。
- 不承诺平台赔付，不免除法律强制要求承担的责任，不自动罚款。

## 对外运营前仍需人工确认

1. 对外展示的实际运营/信息处理者名称及稳定可用的权利请求联系渠道。目前正文使用项目维护者与既有反馈渠道，不虚构公司、学校授权或个人联系电话。
2. 资料保留期限的具体执行安排和删除/更正请求办理流程。正文采用必要期限原则，不声称已实现自动到期清理。
3. 历史余额、保证金和未结订单的核对与处理方案。当前仅停止新资金业务并保留数据，不等于解决了存量资金事项。
4. 详细处置、异议和申诉规则按后续决策公示，不在本次擅自承诺固定时限。
