## 实现结果

- 统一 `CAMPUSHUB_FINANCIAL_FEATURES_ENABLED=false` 默认关闭资金写操作；前端从只读功能接口获取状态，加载失败时保持关闭。
- 钱包入口隐藏，旧 URL 显示未开放说明；原财务组件保留在 `frontend/src/views/legacy/`，管理员财务页只读。
- 顺路跑腿员/闲置发布者明确同意当前协议后免费自动开通；技能店主理人同意后等待站务核验。
- 已开通角色不补签；未付历史申请可转换准入方式，保留历史金额、状态及支付关联。
- 新增 V15 的协议正文版本、同意记录和申请关联；新增乐观锁版本防止并发旧回调覆盖新协议状态。
- 历史支付回调保留原鉴权/幂等处理；关闭不等于存量资金已结清。转换后的历史回调只影响历史支付状态，不撤销新协议准入结果。
- 收紧用户、钱包、任务申请、预约及治理记录读取权限，公开详情不再信任匿名请求伪造的 viewerId。
- UI、页面标题、系统邮件默认名称统一为蜗壳品牌；技术域名和邮箱域名保留；用户生成内容与旧报告未批量重写。
